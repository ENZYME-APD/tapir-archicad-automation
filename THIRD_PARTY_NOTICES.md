## Archicad icons (Graphisoft)

The icons listed below, in
[grasshopper-plugin/TapirGrasshopperPlugin/Resources/](grasshopper-plugin/TapirGrasshopperPlugin/Resources/),
are Archicad user interface icons taken from Graphisoft's Archicad 29 help
(help.graphisoft.com): the toolbox, the Info Box, toolbars, menus, window tabs,
the attribute managers, the Library Manager, the tool settings dialogs, the zoom
controls, palettes and organizers. Where the component has an action, a small
Tapir badge is added in the corner (create, modify, delete, details, replace,
property, unused); the others show the icon alone.
