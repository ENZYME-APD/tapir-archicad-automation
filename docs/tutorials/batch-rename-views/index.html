Tapir / Tutorials / Batch rename views

Batch rename views in Archicad.

Bulk View Renamer, a script that comes with Tapir, renames the views of the View Map, or of one of its folders, in one go. You see every new name before anything is renamed.

  1. 1

    Open the script

    Install the Tapir Add-On with the Tapir Installer, as Get started shows, and start Archicad with a project open. Choose Tapir Palette from the Tapir menu.

    Bulk View Renamer is a built-in script: pick BulkViewRenamer in the palette's list and click Run Script. It lists the views of the View Map with their folder, ID and name. It is also on the Scripts page as Bulk View Renamer.

  2. 2

    Choose the views

    In Views in, choose the whole View Map or one folder; its subfolders are included.

  3. 3

    Choose how the names change

    • Find and replace: Find and Replace with, optionally with Match case and Regular expression.
    • Prefix and suffix: Add before and Add after.
    • Pattern with counter: a Pattern in which {name} is the current name, {id} the view's ID and {n} the counter, with its Start, Step and Digits. The counter counts in View Map order. With the first settings, pattern {name} {n}, start 1 and 2 digits, a first view named Ground Floor becomes Ground Floor 01.
  4. 4

    Check the new names

    The table shows the new names. A clash is a view that would get the same name as another view in its folder; an empty new name is skipped. Select rows to rename only those; Clear selection renames every listed view again.

  5. 5

    Rename

    Press Rename...: the script lists the changes and asks first, then renames the views one at a time and reads the View Map again. Views that could not be renamed are named in the palette's output. Only the names change, not the view IDs or the views' settings.

The commands behind it.

The script reads the View Map with Archicad's own API.GetNavigatorItemTree command and renames each view with the Tapir command RenameNavigatorItem. Its code is builtin-scripts/BulkViewRenamer.py. It works in Archicad 25 to 30 with Tapir 1.8.0 or later.
