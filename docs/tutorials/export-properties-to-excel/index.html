Tapir / Tutorials / Export properties to Excel

Export Archicad element properties to Excel with Python.

Tapir comes with a script for it: Property Value Exporter writes the values of the properties you choose into an Excel workbook or a CSV file, one row per element, without an Interactive Schedule. Property Value Importer reads the edited file back.

  1. 1

    Open the script

    Install the Tapir Add-On with the Tapir Installer, as Get started shows, and start Archicad with a project open. Choose Tapir Palette from the Tapir menu.

    Property Value Exporter is a built-in script, so it is in the palette from the start: pick PropertyValueExporter in the palette's list and click Run Script. It reads every property of the project and opens its window. It is also on the Scripts page as Property Value Exporter.

  2. 2

    Choose the elements and the properties

    • Under Elements, choose Selection, Current story or Whole project, and if you want Only elements on visible layers.
    • Tick the element types to export. All types and No types tick or untick every one.
    • Under Properties, find properties with Search and move them to the Exported list with Add → or a double-click. Up and Down set the order of the columns; ← Remove takes one out again.
    • Tick Precise numbers to export numbers in SI units (m, m², m³, degrees) instead of the values as Archicad displays them. Leave it off for a file you want to read back in.
  3. 3

    Export

    Press Export... and choose the file. Its default name is Property values <date> <time>.xlsx; give it a .csv name for a CSV file. Nothing in the project changes.

    The file has the columns GUID, Element ID, Type and Story, then one column per property, headed <group>: <name>. Rows are sorted by type, story from the bottom up and Element ID. A property an element does not have gives an empty cell. The file cannot be written while it is open in Excel.

  4. 4

    Bring the edited values back

    Edit the values in Excel, then run Property Value Importer. It is not built in: download it from the Scripts page into a folder of your own, with copies of the utilities/ and aclib/ folders of builtin-scripts/ next to it. Add that folder to localFolders in Documents/Tapir/config.json, as Get started shows, then choose Reload scripts... at the bottom of the palette's script list.

    • Press Open file... and choose the .xlsx or .csv file. A row is matched to its element by its GUID, or by its Element ID when it has no GUID.
    • The list shows each value that would change as Current → New, and in red what cannot be written, with the reason. An empty cell leaves the value as it is.
    • Press Write to Archicad and confirm. The values are written in one Undo step, and the Result column says Written or why a value was refused, for example because the property is read-only for that element.

The commands behind it.

Both scripts are Python that sends Tapir commands to Archicad. The exporter lists the properties with GetAllProperties, finds the elements with GetElementsByType or GetSelectedElements, reads their ID, type and story with GetDetailsOfElements and their values with GetPropertyValuesOfElements. The importer writes the values with SetPropertyValuesOfElements.

Their code is builtin-scripts/PropertyValueExporter.py and marketplace/property-value-importer/PropertyValueImporter.py. Both work in Archicad 25 to 30 with Tapir 1.8.0 or later.
