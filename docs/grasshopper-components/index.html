Grasshopper components.

Every component of the Tapir Grasshopper plugin, with its inputs, its outputs and the Tapir commands it calls.

The components are on the Tapir tab of Grasshopper, in the groups listed here. Each one names the Tapir commands it sends to Archicad, linked to the command reference; the Grasshopper coverage page shows which commands still have no component. The tool components (Walls, Doors, Windows, ...) also list the keys of their JSON inputs, the labels of the tool's settings dialog.

This page is generated from the plugin's source code by tools/generate_gh_docs.py, so it shows what the code spells out. A component whose inputs or outputs are built at run time says so; its tooltips in Grasshopper have the full list.
