Tapir and AI.

An AI assistant can read your Archicad project and change it through Tapir. You ask in plain words; it sends the commands to the Archicad running on your computer.

Two ways to connect.

Both talk to the same Tapir commands on port 19723, on your own computer.

While you chat

An MCP server

The AI tool calls Tapir's commands itself, while you chat. Works with tools that support the Model Context Protocol (MCP), such as Claude Desktop.

Tapir MCP servers
Any AI tool

A script the AI writes

Any AI tool can write a short Python script that sends Tapir commands. You read it, then run it from the Tapir palette or a terminal.

A prompt to start with

Start by reading.

Open a project in Archicad, with the Tapir Add-On loaded, and give your AI tool this prompt. It only reads, so it is safe to try on any project.

When the answer looks right, ask for a change in the same plain words, and say exactly which elements it may change: "Set the property X to Y on the selected walls only."

promptread only
Use Tapir to look at the Archicad project I have open.
Do not change anything; only read.
1. List the stories with their names and levels.
2. Count the walls, slabs, columns, doors and windows on each story.
3. Show the result as one table, one row per story.
Tell me which Tapir commands you used.
Check the names first

Check names, don't guess.

Your words rarely match the names in the project: "fire rating" may be a property called FireRating in one template and Feuerwiderstand in another, and "level 2" may be the story "02 First Floor". An AI that guesses the name still gets an answer, only a wrong one: no values found, so "no doors have a fire rating".

01Look the words up firstBefore a command whose parameters come from your words (a story, property, classification, layer, building material, composite, surface, zone category or element type), the AI sends those words to ResolveNames, with the kind of each when it knows it. It only reads.
02Use what it returnsfound: the item named exactly so, with the ids the other commands take (story index, attribute id, elementType, propertyId, classification ids). closeMatches: only similar names, best first; the AI asks you which one you meant instead of picking one itself.
03Say "not in this project"notFound: nothing in the project is close, so the project has no such item. The AI says "this project has no X" instead of guessing a name or reporting an empty result as the answer.

Add these lines to your prompt, or to the instructions of your MCP server, so the AI checks the names every time. They work the same when the AI writes a script: the script sends ResolveNames first and stops with a message on notFound.

Before a change, ask for a preview. The commands that delete or replace, such as DeleteElements, DeleteAttributes and DeleteAndReplaceAttributes, take "dryRun": true: nothing changes, and the response lists what would. The command reference says which commands have it.

promptadd to any request
Before you use a name taken from my words (a story,
property, classification, layer, building material,
composite, surface, zone category or element type),
check it with the Tapir command ResolveNames.
- found: use the ids it returns.
- closeMatches: ask me which one I mean.
- notFound: tell me this project has no such item.
  Never guess a name.
Before a command that deletes or replaces, run it with
"dryRun": true if it has that input, and show me what
it would change.
When the AI writes a script

Describe it, run it.

Without an MCP server, describe the task, give the AI the command list, and run the script it writes.

01Describe what you wantFor example: "Extract all composite exterior walls on level 2 and calculate their net volume."
02Share the command listGive the AI the command reference and the working example below. Ask for Python's standard library only, on port 19723.
03Read it, then run itRead the script before you run it, from the Tapir palette or a terminal. Try one that changes the model on a copy of your project first.
promptfor Claude or any AI tool
Write a Python script that uses only the standard
library and sends Tapir commands to Archicad on
http://127.0.0.1:19723, like the example I attach.
Use the Tapir command reference I attach.

Extract all composite exterior walls on level 2
and calculate their net volume.

Only read the model; change nothing.
tapir_example.pyport 19723
import json
import urllib.request

def run_tapir_command(name, parameters=None, port=19723):
    request = {
        "command": "API.ExecuteAddOnCommand",
        "parameters": {
            "addOnCommandId": {"commandNamespace": "TapirCommand", "commandName": name},
            "addOnCommandParameters": parameters or {},
        },
    }
    with urllib.request.urlopen(f"http://127.0.0.1:{port}", json.dumps(request).encode("utf-8")) as response:
        answer = json.loads(response.read())
    if not answer.get("succeeded"):
        raise RuntimeError(answer.get("error"))
    return answer["result"]["addOnCommandResponse"]

print(run_tapir_command("GetAddOnVersion"))
