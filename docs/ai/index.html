AI tools

Tapir with Claude and other AI tools

An AI assistant can read your Archicad project and change it through Tapir. You ask in plain words; it sends the commands to the Archicad running on your computer.

Two ways to connect

An MCP server

The AI tool calls Tapir's commands itself, while you chat. Works with tools that support the Model Context Protocol (MCP), such as Claude Desktop.

A script the AI writes

Any AI tool can write a short Python script that sends Tapir commands. You read it, then run it from the Tapir palette or a terminal.

Tapir MCP servers

These are community projects, not part of Tapir. Each has its own install steps in its README. Which one Tapir recommends is still being decided in issue #2070, so they are listed here without a recommendation.

tapir-archicad-MCP

By SzamosiMate. The MCP server for Tapir that the others started from.

Careful An MCP server can change your model. Try it on a copy of your project first, and read what the AI is about to do before you allow it.

A prompt to start with

Open a project in Archicad, with the Tapir Add-On loaded, and give your AI tool this prompt. It only reads, so it is safe to try on any project. 

Use Tapir to look at the Archicad project I have open.
Do not change anything; only read.
1. List the stories with their names and levels.
2. Count the walls, slabs, columns, doors and windows on each story.
3. Show the result as one table, one row per story.
Tell me which Tapir commands you used.

When the answer looks right, ask for a change in the same plain words, and say exactly which elements it may change: "Set the property X to Y on the selected walls only."

When the AI writes a script

Without an MCP server, ask the AI for a Python script that uses only Python's standard library and Archicad's local port 19723. Give it this working example and a link to the command reference; it shows how every Tapir command is sent: 

import json
import urllib.request

def run_tapir_command(name, parameters=None, port=19723):
    request = {
        "command": "API.ExecuteAddOnCommand",
        "parameters": {
            "addOnCommandId": {"commandNamespace": "TapirCommand", "commandName": name},
            "addOnCommandParameters": parameters or {},
        },
    }
    with urllib.request.urlopen(f"http://127.0.0.1:{port}", json.dumps(request).encode("utf-8")) as response:
        answer = json.loads(response.read())
    if not answer.get("succeeded"):
        raise RuntimeError(answer.get("error"))
    return answer["result"]["addOnCommandResponse"]

print(run_tapir_command("GetAddOnVersion"))

Read a script before you run it, and try one that changes the model on a copy of your project first.
