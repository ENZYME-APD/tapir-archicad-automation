How it works

How it works.

Tapir is an Archicad add-on that turns native API functions into a stateless JSON server on port 19723. Anything that can send an HTTP request can drive Archicad.

Anatomy of a call

Anatomy of a call

requestPOST 127.0.0.1:19723
{"command": "API.ExecuteAddOnCommand",
 "parameters": {
   "addOnCommandId": {
     "commandNamespace": "TapirCommand",
     "commandName": "GetElementsByType"},
   "addOnCommandParameters": {
     "elementType": "Wall"}}}
response200
{"succeeded": true,
 "result": {
   "addOnCommandResponse": {
     "elements": [
       {"elementId": {"guid": "3F2A…"}},
       …
     ]}}}

Every Tapir command is sent the same way; only commandName and addOnCommandParameters change. Your first Python script →
