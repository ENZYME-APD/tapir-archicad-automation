Get started with Tapir

Five steps from installing Tapir to your first script, in Archicad, in Python and in Grasshopper.

Prefer watching? The Tapir video tutorials walk through installing Tapir and using it.

  1. Install Tapir

    With the installer (recommended). Download the Tapir Installer and run it. It finds the Archicad versions on your computer and installs the matching add-on into each, so Archicad loads it on its next start.

    Installer for Windows Installer for macOS
    • Windows: the installer asks for administrator rights, because it copies the add-on into the Archicad folder under Program Files.
    • macOS: unzip the download and open the app.

    Manually. Download the TapirAddOn_AC<version>_Win.apx or TapirAddOn_AC<version>_Mac.zip file for your Archicad version from the latest release, then in Archicad:

    1. Choose Options > Add-On Manager.
    2. Open Edit List of Available Add-Ons and click Add.
    3. Browse to the downloaded file and click OK.

    Tapir keeps itself up to date: it tells you when a new version is out and installs it for you.

  2. Run a script from the Tapir palette

    Tapir adds a Tapir menu to Archicad. Choose Tapir Palette from it to open the palette.

    1. Pick a script in the palette's list. The built-in scripts, such as ProjectHealthCheck or PropertyHighlighter, are there from the start.
    2. Click Run Script.

    Tapir runs the scripts with uv, which brings the Python and the packages each script needs. If uv is not installed yet, Tapir offers to install it the first time you run a script.

    Manage Shortcuts on the palette puts up to six scripts in the Tapir menu, as Run Script Shortcut 1 to 6.

  3. Find more scripts on the marketplace

    The Tapir marketplace collects scripts shared by the community. Download the ones you want into a folder, then tell Tapir about that folder in its configuration file, Documents/Tapir/config.json in your user folder (Tapir writes it the first time it runs). Add the folder to its localFolders list, keeping the rest of the file as it is: 

    {
    "repositories": [ ... ],
    "localFolders": [
        {
            "displayName": "My scripts",
            "path": "C:\\Users\\me\\Documents\\Tapir scripts"
        }
    ],
    ...
}
    • path is the folder (on macOS for example /Users/me/Documents/Tapir scripts). In JSON, a Windows path's backslashes are doubled.
    • displayName is the name the palette shows for the folder's scripts; without it, the folder's name is used.
    • Optionally, includePattern and excludePattern are regular expressions that choose which files of the folder the palette lists.

    The palette lists the folder's scripts next to the built-in ones the next time it loads its scripts.

  4. Write your first Python script

    Archicad answers JSON commands on http://127.0.0.1:19723 while a project is open (with several Archicads open, the next ones use 19724, 19725 and so on). Tapir's commands are called through Archicad's API.ExecuteAddOnCommand command, in the TapirCommand namespace. This script uses only Python's standard library: 

    import json
import urllib.request

def run_tapir_command(command, parameters=None):
    request = urllib.request.Request('http://127.0.0.1:19723')
    request.add_header('Content-Type', 'application/json')
    body = json.dumps({
        'command': 'API.ExecuteAddOnCommand',
        'parameters': {
            'addOnCommandId': {'commandNamespace': 'TapirCommand', 'commandName': command},
            'addOnCommandParameters': parameters or {}
        }
    }).encode('utf-8')
    with urllib.request.urlopen(request, body) as response:
        result = json.loads(response.read())
    if not result['succeeded']:
        raise RuntimeError(result['error'])
    return result['result']['addOnCommandResponse']

print(run_tapir_command('GetAddOnVersion'))

    It prints the version of the Tapir add-on Archicad has loaded, for example:

    {'version': '1.8.1'}

    The same with Graphisoft's archicad package (pip install archicad), which finds the port by itself: 

    from archicad import ACConnection

conn = ACConnection.connect()
acc = conn.commands
act = conn.types

response = acc.ExecuteAddOnCommand(act.AddOnCommandId('TapirCommand', 'GetAddOnVersion'))
print(response)

    Every command, with its parameters, its response and an example, is in the command reference. Put your script in a local folder to run it from the Tapir palette.

  5. Use Tapir in Grasshopper

    In Rhino, open the Package Manager (the PackageManager command, or Tools > Package Manager), search for tapir, install it and restart Rhino. Its components are on the Tapir tab in Grasshopper and work with the Archicad that runs Tapir.

    The Grasshopper coverage shows which Tapir commands the components call.
