What it does

Six jobs it already does.

Five built-in scripts of the Tapir palette and one workflow script, each a short Python file you can read and change.

  • Built-in script

    Number elements along a line

    Select a polyline and the doors, zones or objects to number. Each one gets its Element ID in the order the polyline passes it.

    Changes the model SetPropertyValuesOfElements

    Automatic Numbering Based on Polyline
  • Built-in script

    Colour the model by a property

    Pick a property; every element gets a colour for its value, with a legend of the values and how many elements have each. Number values can be grouped into ranges.

    Read only HighlightElements

    Property Highlighter
  • Built-in script

    Check a project before it goes out

    Lists elements without an ID, zones with the same number, unclassified and duplicate elements, empty stories and unused layers. Export the list to Excel or turn it into Issues.

    Read only GetClassificationsOfElements

    Project Health Check
  • Built-in script

    Publish on a schedule

    Publishes the chosen Publisher Sets now or on a schedule, every few hours or daily at a set time. It can receive the Teamwork changes and update the drawings first, and logs every run.

    Writes files PublishPublisherSet

    Batch Publisher
  • Built-in script

    Tidy up the View Map

    Finds the views that are neither placed on a layout nor published, and moves the ones you choose into a separate folder that keeps their folder structure.

    Changes the model API.MoveNavigatorItem

    Unused View Cleaner
  • Workflow

    Export the model to OBJ

    Writes the 3D model, or only the selected elements, to a Wavefront OBJ file, one object per element, for Blender and other tools.

    Writes files Get3DGeometryOfElements

    export_obj.py
Your first script

One file, no packages.

With a project open, Archicad answers JSON commands on http://127.0.0.1:19723. Tapir's commands go through Archicad's API.ExecuteAddOnCommand. Save this as walls.py and run it with any Python 3.

With several Archicads open, the next ones answer on 19724, 19725 and so on.

Your first Python script, step by step →

walls.pyport 19723
import json
import urllib.request

def run_tapir_command(command, parameters=None):
    body = json.dumps({
        'command': 'API.ExecuteAddOnCommand',
        'parameters': {
            'addOnCommandId': {'commandNamespace': 'TapirCommand', 'commandName': command},
            'addOnCommandParameters': parameters or {}
        }
    }).encode('utf-8')
    request = urllib.request.Request('http://127.0.0.1:19723', body, {'Content-Type': 'application/json'})
    with urllib.request.urlopen(request) as response:
        result = json.loads(response.read())
    if not result['succeeded']:
        raise RuntimeError(result['error'])
    return result['result']['addOnCommandResponse']

print(run_tapir_command('GetAddOnVersion'))
walls = run_tapir_command('GetElementsByType', {'elementType': 'Wall'})['elements']
print(len(walls), 'walls')
