Tapir commands.

The JSON commands the Tapir add-on registers in Archicad, in the TapirCommand namespace, next to Graphisoft's official commands. Each command shows its parameters, its response and an example.

New to Tapir? Get started shows how to install it and run a first script. Looking for something no command does? What the Archicad API can't do lists what Graphisoft's API does not offer, with what to do instead.

Calling a command.

Archicad answers JSON commands on http://127.0.0.1:19723 while a project is open (the next Archicads opened use 19724, 19725 and so on). A Tapir command is sent through Archicad's API.ExecuteAddOnCommand command.

Python standard library

import json
import urllib.request

def run_tapir_command(command, parameters=None):
    request = urllib.request.Request('http://127.0.0.1:19723')
    request.add_header('Content-Type', 'application/json')
    body = json.dumps({
        'command': 'API.ExecuteAddOnCommand',
        'parameters': {
            'addOnCommandId': {'commandNamespace': 'TapirCommand', 'commandName': command},
            'addOnCommandParameters': parameters or {}
        }
    }).encode('utf-8')
    with urllib.request.urlopen(request, body) as response:
        result = json.loads(response.read())
    if not result['succeeded']:
        raise RuntimeError(result['error'])
    return result['result']['addOnCommandResponse']

print(run_tapir_command('GetAddOnVersion'))

Graphisoft's archicad package

from archicad import ACConnection

conn = ACConnection.connect()
acc = conn.commands
act = conn.types

response = acc.ExecuteAddOnCommand(act.AddOnCommandId('TapirCommand', 'GetAddOnVersion'))
print(response)

The examples of the commands below use aclib, the small helper in archicad-addon/Examples that sends commands the same way as the standard-library script.

The configuration file.

Tapir reads its settings from Documents/Tapir/config.json in your user folder. It writes the file with the defaults below the first time it runs and never changes it afterwards. When you edit the file, Tapir reads it again the next time it needs a setting, so the Tapir Palette uses new script sources the next time it loads its scripts. A key that is missing has its default. This is the file Tapir writes: 

{
    "repositories": [
        {
            "displayName": "Tapir",
            "repoOwner": "ENZYME-APD",
            "repoName": "tapir-archicad-automation",
            "relativeLoc": "builtin-scripts",
            "token": "",
            "excludeFromDownloadPattern": "",
            "includePattern": "",
            "excludePattern": "",
            "uvProject": ""
        }
    ],
    "localFolders": [],
    "askUpdatingAddOnBeforeEachExecution": false,
    "uvLocation": "",
    "pythonLocation": ""
}
KeyTypeWhat it does
repositoriesarrayThe GitHub repositories whose scripts the Tapir Palette lists. Tapir downloads their files when it loads its scripts, and lists the files downloaded before when GitHub can't be reached. Each item has the keys below.
repositories[].displayNamestringThe name the palette shows in brackets after the scripts of the repository.
repositories[].repoOwner, repoNamestringThe repository on GitHub, as in github.com/<repoOwner>/<repoName>.
repositories[].relativeLocstringThe folder of the repository that holds the scripts. Only the files below it are downloaded. Empty: the repository's root.
repositories[].tokenstringA GitHub token, sent as Authorization: Bearer, for a private repository. Empty: no token. The file keeps it as plain text.
repositories[].excludeFromDownloadPatternstringA regular expression. A file whose <repoOwner>/<repoName>/<path> matches it in full is not downloaded.
repositories[].includePattern, excludePatternstringRegular expressions, matched in full against a file's path below relativeLoc. With excludePattern, every file that does not match it is listed, and includePattern is not used. With only includePattern, only the files that match it are listed. With neither, only the .py files directly in relativeLoc are listed.
repositories[].uvProjectstringOptional: the folder of a uv project (its pyproject.toml), relative to relativeLoc, or . for relativeLoc itself. The scripts then run in that project (uv run --project) instead of as standalone scripts with inline metadata (uv run --script).
localFoldersarrayFolders on your computer or a network drive whose scripts the palette lists. Get started shows how to add one. Each item has the keys below.
localFolders[].displayNamestringThe name the palette shows for the folder's scripts.
localFolders[].pathstringThe folder. In JSON, a Windows path's backslashes are doubled.
localFolders[].includePattern, excludePattern, uvProjectstringAs for a repository, relative to the folder.
askUpdatingAddOnBeforeEachExecutionbooleanWhen true, before each script runs Tapir checks for a newer release and offers to update the add-on. Default: false.
uvLocationstringThe path of the uv executable that runs the scripts. Empty: Tapir looks for uv itself and offers to install it. A path that isn't a recent enough uv is reported once, and Tapir then looks for uv itself.
pythonLocationstringThe Python that uv runs the scripts with: the path of an interpreter, or a version request such as 3.12, passed to uv as it is. Empty: uv chooses.
marketplaceCatalogueUrlstringFor testing only, and never written by Tapir: the address the Script Manager reads the marketplace catalogue from instead of the default one.

All commands.

The number at the end of a command's row is the Tapir version it was added in. A badge such as AC29+ before it gives the Archicad versions the command works in, as its description states them (AC29+: Archicad 29 or later, AC25–27: only Archicad 25 to 27). A command without a badge works in every Archicad version Tapir supports. Works in Archicad in the sidebar shows only the commands that work in the Archicad version you pick.
