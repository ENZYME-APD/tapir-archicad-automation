Tapir / Docs / API limits

What the Archicad API can't do.

Tapir uses the Archicad API that Graphisoft publishes for add-ons, and covers all of it that can be a JSON command. What that API does not offer, Tapir cannot offer either. This page lists what people ask for that is not in it, with what to do instead.

The list.

It is also what Tapir would like the Archicad API to offer, and the list Tapir sends to Graphisoft. Every row was checked in the headers of the Archicad API DevKits of Archicad 25 to 30, the versions Tapir is built for; the Evidence column names the headers and functions.

What people want Status What to do instead Evidence Issue
Elements
Explode an element into its parts, as Edit > Reshape > Explode into Current View does Not possible Nothing yet No explode function in ACAPinc.h, the ACAPI_*.h headers or the ACAPI:: modules (AC25–AC30). APIAttrCreationMethod_Explode (APIdefs_Attributes.h) only tells how an attribute was created. –
Anchor the sill or header of a window or door to the project zero or to a reference level Workaround Anchor it to a story with verticalLink SillToStory or HeaderToStory in ModifyWindows or ModifyDoors, and work out the height from the story level (GetStories). API_VerticalLinkID (APIdefs_Elements.h, AC25–AC30) has only the wall bottom, the wall top and a story as the anchor of a window or door (API_LinkSillTo…, API_LinkHeaderTo…); there is no value for the project zero or a reference level. #2575
A camera with a name of its own, or an axonometric camera Partly possible Name the Camera Set the camera is in. For an axonometric view, set the 3D window with Set3DProjectionSettings. API_CameraType holds only head, camSetGuid and perspCam (API_PerspCamPars); only API_CamSetType has a name (APIdefs_Elements.h, AC25–AC30). #2192
Remove one direction of a trim between two roofs or shells that trim each other Workaround Remove the trim with RemoveElementTrims, which removes both directions, then trim the other direction again with TrimElements. The only removal function, ACAPI_Element_Trim_Remove (guid_Element1, guid_Element2) (ACAPinc.h, AC25–AC30), “removes trimming connection between the elements” and takes no direction or trim type. #2365
Read or set the joint type (Vertical Cut and the others) and the dx offset of a stair structure Not possible Nothing yet API_StairStructureType (APIdefs_Elements.h, AC25–AC30) holds structType, bottomType, thicknesses, role, side, isLanding, sequenceNumber, subElemId and API_SideStairStructData or API_MonolithStairStructData; no field, enum or function for the joint type or dx. GetGDLParametersOfElements on stair structure sub-elements fails in Archicad 29 build 3200 (“Failed to get parameters of element”). #2536
Change the baseline of an existing stair (move a flight end, a landing or a winder) and keep its GUID Workaround Recreate the stair on the new baseline with RecreateStairs, which keeps its settings, Element ID, classifications, categories, properties and solid element operations, and returns the old and the new GUID. Its labels are lost. The table of ACAPI_Element_Change (ACAPinc.h) does not list API_StairID among the types whose geometry or memo can change; there is no memo mask for stairBaseLine (only APIMemoMask_StairRiser, StairTread and StairStructure), and ACAPI_Element_ChangeMemo takes only APIMemoMask_Polygon (AC25–AC30). #2532
Set the left and right boundaries or the walking line of a stair (a custom outline, or a walking line off the middle of the flight) Not possible Archicad lays them out from the baseline and the flight width: change the baseline with RecreateStairs or the flight width with ModifyStairs. The walking line stays in the middle of the flight. GetDetailsOfElements reads them. API_ElementMemo holds stairBoundary[2], stairWalkingLine, stairCustomWalkLine and stairCenterWalkLine (APIdefs_Elements.h, AC29–AC30) with no memo mask of their own, and the table of ACAPI_Element_Change (ACAPinc.h) does not list API_StairID. Tried on Archicad 29 build 5101: ACAPI_Element_Change answers APIERR_GENERAL to the stair's memo with APIMemoMask_All or APIMemoMask_Polygon, also when it is unchanged, and ignores the lines with the subelement masks; ACAPI_Element_ChangeExt answers APIERR_BADID; ACAPI_Element_Create lays them out again from the baseline, whatever the memo holds (isCustom stays false). The walkingLinePosition and walkingLineOffset of API_StairType are not kept either, at creation or after: the walking line stays centered. #3014
Read which slab or stair edge a railing is linked to, or link a railing to one Not possible Read the slab's outline with GetDetailsOfElements and create a static railing along the edge with CreateRailings. When the slab changes, delete the railing and create it again. API_RailingType, API_RailingSegmentType and API_RailingNodeType hold no host element or edge; the node has only isStatic (APIdefs_Elements.h, AC25–AC30). ACAPI_Grouping_GetConnectedElements and ACAPI_Element_GetRelations (ACAPinc.h) list no railing connection, and the ACAPI:: modules have no railing API. #2445
Turn off the automatic story visibility of a railing, so the stories it is shown on can be set Not possible Nothing yet API_RailingType has isAutoOnStoryVisibility and visibility (APIdefs_Elements.h, AC27 and AC29), but Archicad 29 keeps isAutoOnStoryVisibility true after ACAPI_Element_Change (with and without the railing’s memo) and ACAPI_Element_ChangeParameters, and then ignores visibility. Archicad 30 is untested. #2448
Set a label’s optimised position, “use text pen as uniform pen” of a symbol label, or a perpendicular text direction Partly possible Set the text direction (parallel, horizontal, vertical or a custom angle) with textWay in CreateLabels and ModifyLabels. When the symbol label’s library part has a parameter for the other two, set it with SetGDLParametersOfElements; otherwise set them in the Label tool settings or a favorite, and create the labels with favoriteName. API_LabelType has no field for an optimised position or a uniform pen (APIdefs_Elements.h, AC25–AC30). Its textWay is documented for labels with only APIDir_Parallel, APIDir_Horizontal, APIDir_Vertical and APIDir_General, not APIDir_Perpendicular. #2666
Set the Floor Plan Display, Show Projection, uncut and overhead lines or the cut line type of a mesh Not possible Nothing yet API_MeshType has no displayOption, viewDepthLimitation, uncut or overhead (aboveView*) line pen or type, and no sectContLtype (APIdefs_Elements.h, AC25–AC30), as API_ShellBaseType of roofs and shells has. Its floor plan members are contPen, ltypeInd, levelPen, sectContPen, the cut fill pens, visibilityCont, visibilityFill and the cover fill, which ModifyMeshes writes. #2630
Read or set the floor plan symbol of a railing: its break mark, which symbol components it shows, their 2D attributes and the symbol overrides Not possible Nothing yet API_RailingType holds only head, linkToSettings, defNode, defSegment, visibility, isAutoOnStoryVisibility, nVertices, referenceLinePen, contourPen, nNodes, nSegments and bottomOffset; neither it nor API_RailingSegmentType, API_RailingNodeType and their post, rail, panel and baluster types has a break mark, symbol component, symbol override or 2D attribute field (APIdefs_Elements.h, AC25–AC30). The break mark fields (breakLinePositionType, breakLineDistance, breakLineAngle) are only in API_StairType, and the ACAPI:: modules have no railing API. #2573
Create a radial dimension of an arc, a circle, a curved wall or a curved slab edge Not documented Place the radial dimension in Archicad and read it with GetDetailsOfElements, which returns how Archicad stored it. Those readings are what a create command needs. API_RadialDimensionType (APIdefs_Elements.h, AC25–AC30) has base (API_DimBase), endC and dimVal but no centre field, and which point base.loc is and which inIndex an arc needs are only shown in an image (neig_rdim.gif). ACAPI_Element_Create (ACAPinc.h) lists API_RadialDimensionID without notes, and the DevKit’s Element_Test example only edits a radial dimension placed by hand (Do_RadialDimension_Edit). #2660
Set the profile modifier values, or the stretched width and height, of a wall, beam or column that uses a profile Partly possible Read them with GetProfileValuesOfElements. To change them, change the profile with CreateProfiles (a copy for these elements, or the profile itself), or set them in the settings of the element in Archicad. API_WallType, API_BeamSegmentType, API_ColumnSegmentType and API_AssemblySegmentData have no field for an element’s modifier values or a wall’s stretch (APIdefs_Elements.h, AC25–AC30). API_ElementMemo holds only the profile geometry (customOrigProfile, stretchedProfile, assemblySegmentProfiles) and customParams, “reserved for internal use”; no ACAPI_* function reads or sets the values. The only table of modifier values is the analytical model’s API_AnalyticalCrossSection::profileParameters (APIdefs_AnalyticalModel.h). #2587
Move a window or door into another wall Not possible Delete it and create it in the other wall with CreateWindows or CreateDoors; a favorite (favoriteName) gives it the same settings. API_WindowType (also API_DoorType) has owner, “Reference to the container wall” (APIdefs_Elements.h, AC25–AC30), but the API_WindowID/API_DoorID row of ACAPI_Element_Change (ACAPinc.h) lists only objLoc, reflected, oSide, refSide, wallCutUsing and libInd as editable fields. Archicad 29 keeps owner after ACAPI_Element_Change with it set in the mask, and no function moves an opening into another wall. Archicad 30 is untested. –
Move a skylight onto another roof or shell Not possible Delete it and create it on the other roof or shell with CreateSkylights. API_SkylightType::owner is the “Reference to the container roof or shell” (APIdefs_Elements.h, AC25–AC30), but API_SkylightID has no row in the supported types of ACAPI_Element_Change (ACAPinc.h), and Archicad 29 keeps owner after the change. –
Turn an automatic zone into a manual one Not possible Delete the zone and create it again as a manual zone, from its polygon, with CreateZones. API_ZoneType::manual is documented “Manually created zone; all edges static, no reference point (refPos)” (APIdefs_Elements.h, AC25–AC30), but the API_ZoneID row of ACAPI_Element_Change (ACAPinc.h) lists only libInd, pos and the polygon of the zone. On Archicad 29 a change that sets manual (with a new polygon) fails, and the zone stays automatic. –
Change the height of a slanted curtain wall Not possible Create it again with CreateCurtainWalls, with its angle and the new height. API_CurtainWallType::angle and height are documented “(input only)” (APIdefs_Elements.h, AC29 and AC30), and API_CurtainWallID has no row in the supported types of ACAPI_Element_Change (ACAPinc.h). On Archicad 29 neither ACAPI_Element_Change nor changed segment contours (cWSegContour, APIMemoMask_CWSegContour) change the height of a slanted curtain wall. –
Move the lines or the arc of an angle dimension Not possible Delete it and create it again with CreateAngleDimensions. The API_AngleDimensionID row of ACAPI_Element_Change (ACAPinc.h) says the note and base fields can be modified, but Archicad 29 keeps base[].loc, pos and radius of API_AngleDimensionType as they were, also with each point marked in the mask, while the pen and the text change. –
Set the position or the offset of a stair's walking line Not possible Nothing yet API_StairType has walkingLinePosition (API_LinePositionID: APILP_Left, APILP_Right, APILP_Center, APILP_Auto) and walkingLineOffset (APIdefs_Elements.h, AC25–AC30), but API_StairID has no row in the supported types of ACAPI_Element_Change (ACAPinc.h), and Archicad 29 keeps a default straight stair at Center, 0.6 m after ModifyStairs asks for Left 0.35 m or Right, although ModifyStairs reports success. The position of the walking line symbol (walkLineSymbPos), on the other hand, is changed. –
Read or set how a grid element is shown in sections, elevations and interior elevations: its vertical extent and its markers at the top and bottom Not possible Select the grid elements in Archicad and set it for all of them at once in their settings dialog. A grid element is an API_ObjectID element with the variation APIVarId_GridElement (APIdefs_Elements.h, AC25–AC30). API_ObjectType has no field for a section, elevation or interior elevation extent or marker, and no header or ACAPI:: module declares a grid element type or function. The grid marker’s GDL parameters (AC_MarkerStart, AC_MarkerEnd, AC_Length, AC_LineVisibility) are its floor plan settings; setting ac_bottomlevel or ac_toplevel changes nothing in an elevation (reported in Archicad 30). #2875
Design options
Read which design option, or the Main Model, is the default that new elements go to Workaround Create a temporary element, read its design option with GetDesignOptionForElements, then move it to the Main Model with MoveElementsToDesignOptions (a null GUID as designOptionId) and delete it with DeleteElements; an element in an option that is not shown cannot be deleted. Set the default with SetDefaultDesignOption. DesignOptionManager has SetDesignOptionAsDefault (DesignOptionsAPI/ACAPI/DesignOptionManager.hpp, AC29–AC30) but no function that returns the default, and DesignOption (DesignOption.hpp) has no default flag. AC27 (DesignVariantAPI) and AC28 have neither; AC25–AC26 have no design options. #2693
Read or change which design options the current window shows, as the eye icons of the Design Options palette do Partly possible Work with saved views: read and set the combination a View Map view shows with GetDesignOptionCombinationOfViews and SetDesignOptionCombinationOfViews, and the options of a combination with SetActiveDesignOptionsInCombinations. DesignOptionManager::GetDesignOptionCombinationSettingsOf takes a View, which only FindViewByGuid (ArchicadAPI/ACAPI/View.hpp) returns, for a View Map item; DesignOptionCombinationViewSettings can only SetMainModelOnly and SetStandardCombination. No function reads or sets the options of the current window (AC27–AC30). #2693
Duplicate a design option or a design option set, as the duplicate button of the Design Options palette does Workaround Create the set and its options with CreateDesignOptionSets and CreateDesignOptions. For the elements, list them with GetElementsOfDesignOptions, copy them with CopyElements and move the copies to the new option with MoveElementsToDesignOptions. DesignOptionManager (DesignOptionsAPI/ACAPI/DesignOptionManager.hpp, AC29–AC30) duplicates only a combination (DuplicateDesignOptionCombination); it has no function that duplicates a design option or a set. AC27–AC28 have none either. #2693
Lock or colour the passive elements of design options, as the Design Options palette does Not possible Nothing yet No passive-element setting in the DesignOptionsAPI headers or the Inc headers (ACAPinc.h, APIdefs_*.h) of AC27–AC30. #2693
Navigator and views
Add an item to a publisher set Not possible Add the items in Archicad's Organizer, then publish the set with PublishPublisherSet. The ACAPI_Navigator_* functions (ACAPI_Navigator.h; APINavigator_*ID in AC25–AC26) create views and folders on the View Map (ACAPI_Navigator_NewNavigatorView, ACAPI_Navigator_CloneProjectMapItemToViewMap) and layouts (ACAPI_Navigator_CreateLayout); ACAPI_Navigator_SetNavigatorItemPosition moves items on the Layout Book and the View Maps only. None adds to a publisher set. Tried on Archicad 30 (build 3001): ACAPI_Navigator_NewNavigatorView with mapId = API_PublisherSets returns APIERR_BADPARS for a folder or a layout item, and crashes Archicad when given an API_NavigatorView; ACAPI_Navigator_SetNavigatorItemPosition and ACAPI_Navigator_CloneProjectMapItemToViewMap with a publisher folder as parent return errors. ACAPI_Navigator_DeleteNavigatorView is documented for views only (AC30), so removing a publisher item is not covered either. #2836
Rename a publisher set Not possible Rename the set in Archicad's Organizer. GetPublisherSets reads the names, and PublishPublisherSet publishes a set by its name. ACAPI_Navigator.h has only ACAPI_Navigator_GetNavigatorSetNum and ACAPI_Navigator_GetNavigatorSet for navigator sets (AC27–AC30; APINavigator_GetNavigatorSetNumID and APINavigator_GetNavigatorSetID in AC25–AC26), which copy the name of a set into an API_NavigatorSet; no function writes a set back. ACAPI_Navigator_ChangeNavigatorItem is documented for View Map items only. Tried on Archicad 30 (build 3001): ACAPI_Navigator_ChangeNavigatorItem with a new name on the root item of a set (its rootGuid) returns NoError and reads the new name back from that item, but the set keeps its name in the Navigator, the Organizer and ACAPI_Navigator_GetNavigatorSet. –
Change, rename or create a stored Model View Options combination Partly possible Read the combinations with GetModelViewOptionDetails; change the options of the current window with SetViewOptions. ACAPinc.h has only ACAPI_Navigator_ModelViewOptions_Get, _GetNum and _Search (AC27–AC30). In AC25–AC26 the combinations are attributes (API_ModelViewOptionsID); not checked there. #781
Read or set the floor plan cut plane or the structural analytical model settings saved in a view Not possible Set them in the view's View Settings in Archicad. The project's floor plan cut plane can be set with SetProjectPreferences. API_NavigatorView (APIdefs_Navigator.h, AC25–AC30), which ACAPI_Navigator_GetNavigatorView, _ChangeNavigatorView and _NewNavigatorView read and write, has no cut plane and no structural analytical field. API_FloorPlanCutDefinition (APIdefs_Environment.h) is the project setting (APIPrefs_FloorPlanCutPlaneDef), not one per view. #2701
Tell a clone folder of the View Map from a normal folder Not possible Give the clone folders a name or ID of their own and find them by it in GetNavigatorItemTree. API_NavigatorItem (APIdefs_Navigator.h, AC25–AC30) has no clone flag, and API_NavigatorItemTypeID has no clone folder type; Archicad 29 reports a clone folder as API_UndefinedNavItem, like a Project Map folder. ACAPI_Navigator.h has no function that reads one. #2701
Change the settings of an existing Layout Book subset (prefix, numbering style, start at, ...) Workaround Read the subset with GetLayoutSubsetSettings, create a subset with the new settings with CreateLayoutSubset and move the layouts into it with MoveNavigatorItem. The old, empty subset is deleted in Archicad. ACAPI_Database.h has only ACAPI_Navigator_GetSubSetDefault, ACAPI_Navigator_CreateSubSet and ACAPI_Navigator_GetSubSet for API_SubSet (AC27–AC30; APIDb_GetSubSetDefaultID, APIDb_CreateSubSetID and APIDb_GetSubSetID in AC25–AC26). No function changes the settings of an existing subset. #2702
Make a 3D style the current one Workaround Give a view the 3D style with SetViewSettings (d3styleName) and open that view with ChangeWindow (navigatorItemId, from Archicad 27). ACAPI_View_SetCurrent3DStyle (ACAPI_Environment.h, AC29 and AC30; APIEnv_SetCurrent3DStyleID in AC25) stops Archicad 29 with the ODB assertion “can't open modification scope inside transaction” when it is called from a JSON command, inside ACAPI_CallUndoableCommand or from ACAPI_AddOnAddOnCommunication_CallFromEventLoop, and an add-on menu command hits the same assertion. API_NavigatorView::d3styleName holds a view’s 3D style: on Archicad 29, a view given a style with SetViewSettings and opened with ChangeWindow makes that style the current one. Archicad 30 is untested. –
Project and files
Undo or redo, as Edit > Undo does Not possible Most Tapir commands change the model in an undo step, so the user can undo them in Archicad; the command reference says which cannot be undone. Save the project with SaveProject before a script that may need to be taken back. ACAPI_CallUndoableCommand (ACAPinc.h) only opens an undo step; APINotifyElement_Undo and APINotifyElement_Redo (APIdefs_Callback.h) only notify. No function runs an undo or a redo (AC25–AC30). #1820
Copy and paste through the clipboard Workaround In a project, copy 2D elements to another view with CopyElementsToDatabase. Between projects, save the elements as a module with SaveAsModuleFile, place it in the other project with CreateHotlinkNodes and CreateHotlinkInstances, and, to keep plain elements, BreakHotlinkNodes. No clipboard, copy or paste function in ACAPinc.h, the ACAPI_*.h headers or the ACAPI:: modules (AC25–AC30). –
Merge a file into the project, as File > Interoperability > Merge does Workaround Place the file as a hotlink with CreateHotlinkNodes and CreateHotlinkInstances, then BreakHotlinkNodes. The project functions (ACAPI_ProjectOperation_*; APIDo_*ID in AC25–AC26) open, create, save, close, print and publish, but none merges. ACAPI_Element_Merge_Elements is the Merge of construction elements, not of files. –
Delete one offset modifier of a profile Workaround Rebuild the profile with CreateProfiles' replaceSkins and newSkins, which drops every modifier, then add the ones to keep again with newProfileModifiers (Archicad 27 and later). ProfileVectorImage (ProfileVectorImage.hpp), ProfileVectorImageOperations and VI::ProfileVectorImageBuilder only add parameters, anchors and dimension control tools (AddProfileParameter, AddOffsetParameter, AddOffsetParameterSetup, AddAnchor, AddDimControlTool); none removes one, and DisableControlViaParameter only disables its control (AC25–AC30). #2586
Import an IFC translator from a file into the project, or export one to a file Not possible Keep the office translator in the project template, so new projects have it, and bring it into older projects once with Import… in the IFC Translators dialog. A script can check that a project has it with GetIFCExportTranslators and export with it by name with IFCFileOperation. The IFC translator functions only list the export translators (ACAPI_IFC_GetIFCExportTranslatorsList, AC26–AC30; APIAny_GetIFCExportTranslatorsListID in AC25), read their relationship data (ACAPI_IFC_GetIFCRelationshipData) and open the export settings dialog (ACAPI_IFC_InvokeIFCExportSettingsDlg, AC28–AC30). API_IFCTranslatorIdentifier (APIdefs_Automate.h) has only an internal reference and a name. No function imports, exports, creates or deletes a translator, in ACAPinc.h or the IFCInOutAPI module (AC25–AC30). #2944
Read the settings of an IFC translator, such as its type mapping and property mapping, for example to check them as the IFC conformity check of the Missing BIM Data report does Partly possible Check what the translator gives the elements instead: their IFC type with GetIFCTypeOfElements, and from Archicad 28 the properties and classification references the preview translator maps to them with GetIFCPropertiesOfElements and GetIFCClassificationReferencesOfElements. GetAllProperties shows whether the properties a mapping needs exist in the project. API_IFCTranslatorIdentifier (APIdefs_Automate.h) has only an internal reference and a name. The IFC translator functions only list the export translators (ACAPI_IFC_GetIFCExportTranslatorsList, AC26–AC30; APIAny_GetIFCExportTranslatorsListID in AC25) and open the export settings dialog (ACAPI_IFC_InvokeIFCExportSettingsDlg, AC28–AC30). The IFCInOutAPI module (AC28–AC30) reads what the preview translator maps to one element (IFCAPI::PropertyAccessor::GetPreviewProperties, GetPreviewClassificationReferences), not the mappings. No function reads a translator’s type mapping, property mapping or other settings, or runs a check of them (AC25–AC30). #2110
Find the graphic override rules, Interactive Schedules and SAF translators that refer to a property or classification that no longer exists, as the Missing BIM Data report does Partly possible For graphic override rules (from Archicad 27): read the criterion of each rule with GetGraphicOverrideRules (includeCriterion) and compare the properties and classifications it tests with GetAllProperties and GetAllClassificationSystems. For Interactive Schedules and SAF translators: nothing yet. A rule’s criterion is API_OverrideRule::criterionXML (APIdefs_Environment.h), read with ACAPI_GraphicalOverride_GetOverrideRuleList and _GetOverrideRuleById (AC27–AC30; ACAPI_Override_GetOverrideRuleList and _GetOverrideRule in AC25–AC26). A schedule is only a Project Map item (API_ScheduleNavItem, APIdefs_Navigator.h); no function reads its fields or criteria. A SAF translator appears only as a name to export with (API_SavePars_Saf::selectedSAFTranslatorName, APIdefs_Automate.h, AC26–AC30); no function lists or reads SAF translators. The report itself goes to the Session Report window, which no function reads (see that row) (AC25–AC30). #2109
Export and import, all at once, the settings that the dialogs of Archicad save as XML (properties, classifications, the Layout Book, graphic overrides, Model View Options, IFC and DWG translators), to keep several projects in sync Partly possible Copy what the API can write, one kind at a time, in one script run against each project: properties and classifications from their XML files with ImportPropertiesXml and ImportClassificationsXml; attributes from another project with ImportAttributesFromProject; graphic override rules with GetGraphicOverrideRules and CreateGraphicOverrideRules; Project Info with GetProjectInfoFields and SetProjectInfoField; Favorites with ExportFavorites and ImportFavorites. The Layout Book, Model View Options and the translators: nothing yet. The only XML imports are ACAPI_Property_Import and ACAPI_Classification_Import (ACAPinc.h); nothing exports properties or classifications to XML. ACAPI_Favorite_Export and _Import write and read Favorites files. No function imports or exports the Layout Book, graphic override rules or combinations, Model View Options, or the IFC or DWG translators (ACAPinc.h, the ACAPI_*.h headers and the IFCInOutAPI module, AC25–AC30). #2113
Documents and publishing
Read the rows of an Interactive Schedule Not possible Build the list yourself: find the elements with GetElementsByType and read their values with GetPropertyValuesOfElements or GetQuantitiesOfElements. The built-in scripts Room Finishes Schedule and Material Take-Off build such lists. A schedule appears only as a Project Map item (API_ScheduleNavItem, APIdefs_Navigator.h), a view node (API_ViewNodeSchedule) and a window type (APIWind_IESCommonDrawingID, APIdefs_Database.h). No function returns its rows (AC25–AC30). –
Export an Interactive Schedule Workaround Put the schedule in a publisher set in Archicad once, then publish that set with PublishPublisherSet. No schedule export function (AC25–AC30); ACAPI_ProjectOperation_Publish (APIDo_PublishID in AC25–AC26) publishes a whole publisher set. –
Choose the output format (PDF, DWG, DXF …) of a publisher set per call Workaround Make one publisher set per format in Archicad’s Organizer once, then publish the one you need with PublishPublisherSet; its answer lists the files written (writtenFiles). API_PublishPars (APIdefs_Automate.h, AC25–AC30) has only the set’s guid and an output path. The format of an item is API_NavigatorItem::mimeType (APIdefs_Navigator.h, AC29–AC30 only), which nothing writes: ACAPI_Navigator_ChangeNavigatorItem changes the name or ID of View Map items only. #2801
Create a revision Change without placing a Change Marker, or change the ID or description of an existing Change Partly possible Create the Change together with its first marker with CreateChangeMarkers (createChange). To change an existing Change, use Archicad’s Change Manager. The ACAPI_Revision_* functions (ACAPI_Database.h, AC27–AC30; APIDb_*RVM*ID in AC25–AC26) read Changes; the only one that writes, ACAPI_Revision_ChangeRVMIssue, changes an Issue. A Change is only created by ACAPI_Element_Create/ACAPI_Element_CreateExt of a Change Marker with linkType APICMLT_CreateNewChange (API_ChangeMarkerType, APIdefs_Elements.h). #2658
Set the custom scheme fields of a revision Change Not possible Fill them in Archicad’s Change Manager; GetRevisionChanges reads them back. API_RVMChange::customData (APIdefs_Database.h) is only filled by the reading functions; no ACAPI_Revision_* functions (ACAPI_Database.h, AC27–AC30; APIDb_*RVM*ID in AC25–AC26) writes a Change, and API_ChangeMarkerType has only changeId and changeName (AC25–AC30). #2658
Add elements to a revision Change, or remove them from it Not possible Add them in Archicad’s Change Manager; GetRevisionChangesOfElements reads which Changes an element belongs to. ACAPI_Revision_GetRVMElemChangeIds (APIDb_GetRVMElemChangeIdsID in AC25–AC26) only reads the Changes of an element; no function writes them (AC25–AC30). #2658
Library parts and GDL
Run a 2D GDL script given as text, as InterpretGDLScript3D does with a 3D script Workaround Save the script in a library part with CreateLibraryParts (or SetLibraryPartScripts), then draw its 2D symbol with GetLibraryPart2DPrimitives. The only GDL interpreter function is ACAPI_LibraryManagement_InterpretGDLScript3D (ACAPI_Goodies.h, AC27–AC30; APIAny_InterpretGDLScript3DID in AC25–AC26), for a 3D script; there is no 2D counterpart (AC25–AC30). ACAPI_LibraryPart_ShapePrims (ACAPinc.h, AC27–AC30; ACAPI_LibPart_ShapePrims in AC25–AC26) draws the 2D symbol of a loaded library part that can be placed on the floor plan, with its default parameters or those of a placed instance. –
Get the error message and the line number when a GDL script fails Not possible Check whether the script runs with InterpretGDLScript3D (3D) or GetLibraryPart2DPrimitives (2D). To see the error, open the library part in Archicad’s GDL editor with OpenLibraryPartInEditor (from Archicad 27). ACAPI_LibraryManagement_InterpretGDLScript3D returns only APIERR_GENERAL, “Failed to interpret the script” (ACAPI_Goodies.h), and ACAPI_LibraryPart_ShapePrims only error codes (ACAPinc.h). ACAPI::Library::GSMObject (AC28–AC30) reads and writes the scripts but has no function that checks or compiles them, and no function returns a GDL error message or line number (AC25–AC30). –
Archicad's interface
Read the text of the Session Report window Not possible Open the window for the user with ChangeWindow and windowType 'Report' (from Archicad 26). ACAPI_WriteReport (ACAPinc.h) writes to it and ACAPI_Dialog_ActivateSessionReport (ACAPI_Goodies.h, AC27–AC30; APIAny_ActivateSessionReportID in AC26) opens it; no function reads it (AC25–AC30). #1707
Get the outcome of an Action Center check Partly possible Run the check with RunActionCenterChecks; Archicad shows the Action Center when it found an issue. For the hotlink check, read the state of each source with GetHotlinkSourceStatus (from Archicad 27). ACAPI_Window_Check (ACAPinc.h, AC27–AC30; ACAPI_ActionCenter_Check in AC25–AC26) returns only an error code; API_ActionCenterItemID (APIdefs_ActionCenter.hpp) has only APIActionCenterItem_Hotlinks. –
Load a new add-on (.apx or .bundle) while Archicad runs, from an add-on or a script Not possible Add it in Archicad's Add-On Manager (Options > Add-On Manager > Edit List of Available Add-Ons > Add). An add-on that is already loaded is replaced only after Archicad quits, as the Tapir Installer does when it updates Tapir. Archicad loads an add-on itself and calls its CheckEnvironment, RegisterInterface, Initialize and FreeData; API_AddonType (APIAddon_Normal, APIAddon_Preload, APIAddon_DontRegister; APIdefs_Registration.h) and ACAPI_KeepInMemory (ACAPinc.h) only steer the add-on's own loading. No function loads, registers or reloads another add-on (AC25–AC30). #2732
