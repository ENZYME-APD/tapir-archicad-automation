What the Archicad API can't do.

Tapir uses the Archicad API that Graphisoft publishes for add-ons, and covers all of it that can be a JSON command. What that API does not offer, Tapir cannot offer either. This page lists what people ask for that is not in it, with what to do instead.

The list.

It is also what Tapir would like the Archicad API to offer, and the list Tapir sends to Graphisoft. Every row was checked in the headers of the Archicad API DevKits of Archicad 25 to 30, the versions Tapir is built for; the Evidence column names the headers and functions.

What people want Status What to do instead Evidence Issue
Elements
Explode an element into its parts, as Edit > Reshape > Explode into Current View does Not possible Nothing yet No explode function in ACAPinc.h, the ACAPI_*.h headers or the ACAPI:: modules (AC25–AC30). APIAttrCreationMethod_Explode (APIdefs_Attributes.h) only tells how an attribute was created. –
Anchor the sill or header of a window or door to the project zero or to a reference level Workaround Anchor it to a story with verticalLink SillToStory or HeaderToStory in ModifyWindows or ModifyDoors, and work out the height from the story level (GetStories). API_VerticalLinkID (APIdefs_Elements.h, AC25–AC30) has only the wall bottom, the wall top and a story as the anchor of a window or door (API_LinkSillTo…, API_LinkHeaderTo…); there is no value for the project zero or a reference level. #2575
A camera with a name of its own, or an axonometric camera Partly possible Name the Camera Set the camera is in. For an axonometric view, set the 3D window with Set3DProjectionSettings. API_CameraType holds only head, camSetGuid and perspCam (API_PerspCamPars); only API_CamSetType has a name (APIdefs_Elements.h, AC25–AC30). #2192
Remove one direction of a trim between two roofs or shells that trim each other Workaround Remove the trim with RemoveElementTrims, which removes both directions, then trim the other direction again with TrimElements. The only removal function, ACAPI_Element_Trim_Remove (guid_Element1, guid_Element2) (ACAPinc.h, AC25–AC30), “removes trimming connection between the elements” and takes no direction or trim type. #2365
Read or set the joint type (Vertical Cut and the others) and the dx offset of a stair structure Not possible Nothing yet API_StairStructureType (APIdefs_Elements.h, AC25–AC30) holds structType, bottomType, thicknesses, role, side, isLanding, sequenceNumber, subElemId and API_SideStairStructData or API_MonolithStairStructData; no field, enum or function for the joint type or dx. GetGDLParametersOfElements on stair structure sub-elements fails in Archicad 29 build 3200 (“Failed to get parameters of element”). #2536
Change the baseline of an existing stair (move a flight end, a landing or a winder) and keep its GUID Workaround Recreate the stair on the new baseline with RecreateStairs, which keeps its settings, Element ID, classifications, categories, properties and solid element operations, and returns the old and the new GUID. Its labels are lost. The table of ACAPI_Element_Change (ACAPinc.h) does not list API_StairID among the types whose geometry or memo can change; there is no memo mask for stairBaseLine (only APIMemoMask_StairRiser, StairTread and StairStructure), and ACAPI_Element_ChangeMemo takes only APIMemoMask_Polygon (AC25–AC30). #2532
Read which slab or stair edge a railing is linked to, or link a railing to one Not possible Read the slab's outline with GetDetailsOfElements and create a static railing along the edge with CreateRailings. When the slab changes, delete the railing and create it again. API_RailingType, API_RailingSegmentType and API_RailingNodeType hold no host element or edge; the node has only isStatic (APIdefs_Elements.h, AC25–AC30). ACAPI_Grouping_GetConnectedElements and ACAPI_Element_GetRelations (ACAPinc.h) list no railing connection, and the ACAPI:: modules have no railing API. #2445
Turn off the automatic story visibility of a railing, so the stories it is shown on can be set Not possible Nothing yet API_RailingType has isAutoOnStoryVisibility and visibility (APIdefs_Elements.h, AC27 and AC29), but Archicad 29 keeps isAutoOnStoryVisibility true after ACAPI_Element_Change (with and without the railing’s memo) and ACAPI_Element_ChangeParameters, and then ignores visibility. Archicad 30 is untested. #2448
Set the Floor Plan Display, Show Projection, uncut and overhead lines or the cut line type of a mesh Not possible Nothing yet API_MeshType has no displayOption, viewDepthLimitation, uncut or overhead (aboveView*) line pen or type, and no sectContLtype (APIdefs_Elements.h, AC25–AC30), as API_ShellBaseType of roofs and shells has. Its floor plan members are contPen, ltypeInd, levelPen, sectContPen, the cut fill pens, visibilityCont, visibilityFill and the cover fill, which ModifyMeshes writes. #2630
Read or set the floor plan symbol of a railing: its break mark, which symbol components it shows, their 2D attributes and the symbol overrides Not possible Nothing yet API_RailingType holds only head, linkToSettings, defNode, defSegment, visibility, isAutoOnStoryVisibility, nVertices, referenceLinePen, contourPen, nNodes, nSegments and bottomOffset; neither it nor API_RailingSegmentType, API_RailingNodeType and their post, rail, panel and baluster types has a break mark, symbol component, symbol override or 2D attribute field (APIdefs_Elements.h, AC25–AC30). The break mark fields (breakLinePositionType, breakLineDistance, breakLineAngle) are only in API_StairType, and the ACAPI:: modules have no railing API. #2573
Set the profile modifier values, or the stretched width and height, of a wall, beam or column that uses a profile Partly possible Read them with GetProfileValuesOfElements. To change them, change the profile with CreateProfiles (a copy for these elements, or the profile itself), or set them in the settings of the element in Archicad. API_WallType, API_BeamSegmentType, API_ColumnSegmentType and API_AssemblySegmentData have no field for an element’s modifier values or a wall’s stretch (APIdefs_Elements.h, AC25–AC30). API_ElementMemo holds only the profile geometry (customOrigProfile, stretchedProfile, assemblySegmentProfiles) and customParams, “reserved for internal use”; no ACAPI_* function reads or sets the values. The only table of modifier values is the analytical model’s API_AnalyticalCrossSection::profileParameters (APIdefs_AnalyticalModel.h). #2587
Navigator and views
Add an item to a publisher set Not possible Add the items in Archicad's Organizer, then publish the set with PublishPublisherSet. The ACAPI_Navigator_* functions (ACAPI_Navigator.h; APINavigator_*ID in AC25–AC26) create views and folders on the View Map (ACAPI_Navigator_NewNavigatorView, ACAPI_Navigator_CloneProjectMapItemToViewMap) and layouts (ACAPI_Navigator_CreateLayout); ACAPI_Navigator_SetNavigatorItemPosition moves items on the Layout Book and the View Maps only. None adds to a publisher set. –
Change, rename or create a stored Model View Options combination Partly possible Read the combinations with GetModelViewOptionDetails; change the options of the current window with SetViewOptions. ACAPinc.h has only ACAPI_Navigator_ModelViewOptions_Get, _GetNum and _Search (AC27–AC30). In AC25–AC26 the combinations are attributes (API_ModelViewOptionsID); not checked there. #781
Project and files
Undo or redo, as Edit > Undo does Not possible Most Tapir commands change the model in an undo step, so the user can undo them in Archicad; the command reference says which cannot be undone. Save the project with SaveProject before a script that may need to be taken back. ACAPI_CallUndoableCommand (ACAPinc.h) only opens an undo step; APINotifyElement_Undo and APINotifyElement_Redo (APIdefs_Callback.h) only notify. No function runs an undo or a redo (AC25–AC30). #1820
Copy and paste through the clipboard Workaround In a project, copy 2D elements to another view with CopyElementsToDatabase. Between projects, save the elements as a module with SaveAsModuleFile, place it in the other project with CreateHotlinkNodes and CreateHotlinkInstances, and, to keep plain elements, BreakHotlinkNodes. No clipboard, copy or paste function in ACAPinc.h, the ACAPI_*.h headers or the ACAPI:: modules (AC25–AC30). –
Merge a file into the project, as File > Interoperability > Merge does Workaround Place the file as a hotlink with CreateHotlinkNodes and CreateHotlinkInstances, then BreakHotlinkNodes. The project functions (ACAPI_ProjectOperation_*; APIDo_*ID in AC25–AC26) open, create, save, close, print and publish, but none merges. ACAPI_Element_Merge_Elements is the Merge of construction elements, not of files. –
Documents and publishing
Read the rows of an Interactive Schedule Not possible Build the list yourself: find the elements with GetElementsByType and read their values with GetPropertyValuesOfElements or GetQuantitiesOfElements. The built-in scripts Room Finishes Schedule and Material Take-Off build such lists. A schedule appears only as a Project Map item (API_ScheduleNavItem, APIdefs_Navigator.h), a view node (API_ViewNodeSchedule) and a window type (APIWind_IESCommonDrawingID, APIdefs_Database.h). No function returns its rows (AC25–AC30). –
Export an Interactive Schedule Workaround Put the schedule in a publisher set in Archicad once, then publish that set with PublishPublisherSet. No schedule export function (AC25–AC30); ACAPI_ProjectOperation_Publish (APIDo_PublishID in AC25–AC26) publishes a whole publisher set. –
Create a revision Change without placing a Change Marker, or change the ID or description of an existing Change Partly possible Create the Change together with its first marker with CreateChangeMarkers (createChange). To change an existing Change, use Archicad’s Change Manager. The ACAPI_Revision_* functions (ACAPI_Database.h, AC27–AC30; APIDb_*RVM*ID in AC25–AC26) read Changes; the only one that writes, ACAPI_Revision_ChangeRVMIssue, changes an Issue. A Change is only created by ACAPI_Element_Create/ACAPI_Element_CreateExt of a Change Marker with linkType APICMLT_CreateNewChange (API_ChangeMarkerType, APIdefs_Elements.h). #2658
Set the custom scheme fields of a revision Change Not possible Fill them in Archicad’s Change Manager; GetRevisionChanges reads them back. API_RVMChange::customData (APIdefs_Database.h) is only filled by the reading functions; no ACAPI_Revision_* functions (ACAPI_Database.h, AC27–AC30; APIDb_*RVM*ID in AC25–AC26) writes a Change, and API_ChangeMarkerType has only changeId and changeName (AC25–AC30). #2658
Add elements to a revision Change, or remove them from it Not possible Add them in Archicad’s Change Manager; GetRevisionChangesOfElements reads which Changes an element belongs to. ACAPI_Revision_GetRVMElemChangeIds (APIDb_GetRVMElemChangeIdsID in AC25–AC26) only reads the Changes of an element; no function writes them (AC25–AC30). #2658
Archicad's interface
Read the text of the Session Report window Not possible Open the window for the user with ChangeWindow and windowType 'Report' (from Archicad 26). ACAPI_WriteReport (ACAPinc.h) writes to it and ACAPI_Dialog_ActivateSessionReport (ACAPI_Goodies.h, AC27–AC30; APIAny_ActivateSessionReportID in AC26) opens it; no function reads it (AC25–AC30). #1707
Get the outcome of an Action Center check Partly possible Run the check with RunActionCenterChecks; Archicad shows the Action Center when it found an issue. For the hotlink check, read the state of each source with GetHotlinkSourceStatus (from Archicad 27). ACAPI_Window_Check (ACAPinc.h, AC27–AC30; ACAPI_ActionCenter_Check in AC25–AC26) returns only an error code; API_ActionCenterItemID (APIdefs_ActionCenter.hpp) has only APIActionCenterItem_Hotlinks. –

Found something else the Archicad API cannot do? Say so in an issue, with the DevKit headers you checked, and it is added here. Open an issue
