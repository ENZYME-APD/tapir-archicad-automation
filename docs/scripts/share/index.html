Share a script

Wrote a script that saves you time in Archicad? Share it, and other offices can use it too. You don't need a GitHub account, and we do the work to make it ready.

Three ways to send it

From the Tapir palette

The palette is getting a Share button: pick your script, add a few words about it, send. Until your palette has it, use Discord.

On Discord

Post the script in the #share-a-script channel, with a few words on what it does and which Archicad version you use.

Join Discord

As a pull request

If you use GitHub: add a folder marketplace/<name>/ with the script, a listing.json and a README, as the marketplace README describes.

The marketplace folder

What happens next

  1. Your script arrives as an issue on GitHub labelled script-share.
  2. Tapir's bot, an AI, adapts it for other offices and opens a pull request with the changes.
  3. You are asked to try the adapted version and say whether it still does what you meant.
  4. The pull request is reviewed and merged, and your script shows on the Scripts page.

What the AI changes

It keeps what your script does. It changes how, so the script is safe and works in other offices, and lists every change in plain words in the pull request.

Made safe

These are removed, or flagged for a maintainer when the script can't work without them:

  • connections to anything other than Archicad on your own computer;
  • running other programs or code built from text (subprocess, os.system, eval, exec);
  • installing packages while it runs (pip install);
  • deleting or overwriting files, and writing anywhere but the project's folder and Documents/Tapir;
  • passwords, tokens and keys;
  • user names, C:\Users\… paths, and project, client and office names, in the code and its comments.

Made to fit other offices

  • Property names, layers, stories, paths and classification codes you typed in become settings at the top of the script, or fields of its window.
  • Built-in properties are found by their ID, so the script works in every language of Archicad.
  • Lengths and areas work in metric and imperial units; paths work on Windows and macOS.

Made safe to run

  • It says what it is about to change, and does nothing, saying so, when nothing fits.
  • It makes its changes in one Undo step where it can.
  • When a property or element type it needs is missing, it shows a clear message instead of crashing.

Described

  • A README in plain words: what it does, how to use it, its settings, what it changes, its limits, and Original by you.
  • Its category, the Archicad and Tapir versions it works with, and whether it changes the model or only reads it.

What the review checks

Every pull request is reviewed before it is merged, like any other code in Tapir. The review checks that:

  • nothing on the Made safe list is left in, unless a maintainer agreed to it;
  • the script still does what you wrote it for, and you confirmed that;
  • the folder has the files and fields the marketplace format asks for;
  • the README is accurate, and the screenshots show no client, project or people.

Licence

Every script in the Marketplace is free and open source. Unless you choose another open-source licence, yours is published under the MIT licence: anyone may use, change and share it, as long as they keep your name and the licence with it. It comes without warranty. You stay its author, and the page credits you.

Only share a script you wrote, or one whose author agreed to share it.
