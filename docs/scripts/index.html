      Install it from the palette

      1. Check that Archicad and the Tapir Add-On are new enough: see Archicad and Tapir Add-On above.
      2. In the Tapir palette, open the Marketplace, find and install it. It then shows in the palette's script list.
      3. If your palette has no Marketplace yet: download the script with the button above into a folder of yours, and add that folder to the palette, as Get started shows.
      4. Open the project, select what the script's description asks for, and run it from the palette.
