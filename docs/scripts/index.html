    Install in Tapir
    1. Check that Archicad and Tapir are new enough: see Archicad and Tapir above.
    2. When your Tapir palette lists scripts to install, find there and install it.
    3. Until then, download the script into a folder and add that folder to the palette, as Get started shows.
    4. Open the project, select what the script asks for, and run it from the palette.
