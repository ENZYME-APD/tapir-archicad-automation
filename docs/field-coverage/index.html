Field coverage.

Which settings of each Archicad element type a Tapir command has a key for, and which a script reaches only through the generic field commands.

Every field of every element type of the Archicad API (API_WallType.thickness, API_RoofType.shellBase.topMat, …), and whether code of the Tapir Add-On writes or reads it by name, so that a command most likely has a key of its own for it. The rest a script reaches only through GetElementFields and SetElementFields, on Archicad 29 and 30. This is a static estimate from the code, updated with every push to main: "written" does not prove that a command takes the field as input. See also the command reference and the Archicad API coverage.
